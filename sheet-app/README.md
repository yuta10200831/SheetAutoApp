# Sheet Auto App (スプレッドシート自動化アプリ)

Google Sheets API と Java (Spring Boot) を使用して、Google スプレッドシートの操作を自動化するアプリケーションです。

## 🎯 現在実装されている機能

### 1. 月次でのグループ自動開閉機能
毎月1日になると、スプレッドシートの「全体」タブの表示を自動的に整理します。

*   **過去のデータを折りたたむ**: 1月1日から先月末までのデータを1つの大きなグループにまとめ、自動的に閉じた状態（折りたたみ状態）にします。
*   **今月のデータを表示**: 今月分のデータ範囲はグループ化せず、そのまま開いた状態で表示します。
*   **完全自動化**: Spring Boot の `@Scheduled` 機能を使用し、毎日深夜0時に自動でチェック・実行されます（手動での操作は不要です）。

### 2. スプレッドシート操作の基盤（GoogleSheetsService）
Google Sheets API を利用して、スプレッドシートに対して以下のような操作を行うための基盤（メソッド）が整っています。

*   `getSheetData`: 指定した範囲のデータを読み取る
*   `writeData`: 指定した範囲にデータを書き込む（数式も可）
*   `formatHeaderCells`: セルの背景色や文字の太さを変更する（書式設定）
*   `addRowGroup`: 指定した行の範囲をグループ化する
*   `updateRowGroupState`: 既存のグループを開く（展開）または閉じる（折りたたむ）
*   `deleteRowGroups`: シート内の既存のグループをすべて削除してリセットする

## 🚀 実行方法

### ローカルでの実行

1.  プロジェクトのルートディレクトリ（`sheet-app` フォルダ）に移動します。
2.  以下のコマンドを実行して、Spring Boot アプリケーションを起動します。

```bash
./mvnw spring-boot:run
```

3.  アプリケーションが起動すると、ターミナルに以下のように表示され、バックグラウンドでタイマーが待機状態になります。

```text
=========================================
Spring Boot アプリケーションが起動しました！
タイマー（MonthlySheetTask）がバックグラウンドで待機中です。
=========================================
```

※ この状態でPCを起動したままにしておくと、毎日深夜0時に自動で処理が走ります。

## 🔑 認証情報について

このアプリケーションは、Google Cloud Platform (GCP) のサービスアカウントを使用してスプレッドシートにアクセスします。

*   認証情報ファイル: `src/main/resources/credentials.json`
*   対象のスプレッドシートには、このサービスアカウントのメールアドレス（`my-sheet-bot-831@...`）に対して「編集者」権限が付与されている必要があります。

*   **Render などの無料クラウドサービスへのデプロイ**: PCを閉じていても24時間365日自動でタイマーが動くようにする。
*   **条件付き書式の自動設定**: 特定の条件（例：学習時間が0時間）を満たすセルを自動で赤く塗りつぶす。
*   **グラフの自動生成**: 入力されたデータをもとに、Java から自動的にグラフを作成・更新する。
*   **別シートへの自動集計**: 日々の学習時間データを読み取り、月ごとの合計を別タブに自動で書き込む。
