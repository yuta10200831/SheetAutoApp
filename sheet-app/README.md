# Sheet Auto App (スプレッドシート自動化アプリ)

Google Sheets API と Java (Spring Boot) を使用して、Google スプレッドシートの操作を自動化するアプリケーションです。
GitHub Actions を利用して、PCを閉じていても毎日自動で実行されるように構築されています。

## 🎯 現在実装されている機能

### 日次でのグループ自動開閉機能
毎日深夜0時（日本時間）になると、スプレッドシートの表示を自動的に整理します。

*   **「全体」シート（行のグループ化）**: 
    *   2行目から「昨日の日付の行」までを自動でグループ化して閉じます。
    *   今日の日付の行がすぐに見える状態を維持します。
*   **「学習時間を入れていく」シート（行と列のグループ化）**: 
    *   列方向: C列から「昨日の日付の列」までを自動でグループ化して閉じます。
    *   行方向: 5行目から「昨日の日付に対応する行」までを自動でグループ化して閉じます。
    *   斜めに入力していく特殊なフォーマットに合わせて、常に今日の入力箇所が左上に表示されるように整理します。

### 完全自動化（サーバーレス運用）
*   **GitHub Actions** を使用し、毎日日本時間の深夜0時に自動でプログラムが起動・実行・終了します。
*   自分のPCを起動しっぱなしにする必要はなく、サーバー代もかからない完全無料の自動化システムです。

## 🚀 実行方法

### 1. GitHub Actions での自動実行（本番環境）
*   `.github/workflows/daily-update.yml` の設定により、毎日日本時間の 0:00 に自動実行されます。
*   手動で今すぐ実行したい場合は、GitHub リポジトリの `Actions` タブ ➡️ `Daily Sheet Auto Update` ➡️ `Run workflow` から実行可能です。

### 2. ローカルでの手動実行（開発・テスト用）
開発中やテスト目的で自分のPCで動かす場合は、以下の手順を実行します。

1.  プロジェクトのディレクトリ（`sheet-app` フォルダ）に移動します。
2.  以下のコマンドを実行して、Spring Boot アプリケーションを起動します。

```bash
./mvnw spring-boot:run
```

3.  アプリケーションが起動すると、即座にスプレッドシートの更新処理が走り、処理が完了すると自動的にアプリケーションが終了します。

## 🔑 認証情報について

このアプリケーションは、Google Cloud Platform (GCP) のサービスアカウントを使用してスプレッドシートにアクセスします。

*   **ローカル開発時**: `src/main/resources/credentials.json` に鍵ファイルを配置します。
*   **GitHub Actions 実行時**: GitHub リポジトリの `Settings` ➡️ `Secrets and variables` ➡️ `Actions` にて、`GOOGLE_CREDENTIALS` という名前で鍵ファイルの中身を登録して使用します。
*   対象のスプレッドシートには、このサービスアカウントのメールアドレスに対して「編集者」権限が付与されている必要があります。

## 💡 今後の拡張アイデア

*   **条件付き書式の自動設定**: 特定の条件（例：学習時間が0時間）を満たすセルを自動で赤く塗りつぶす。
*   **グラフの自動生成**: 入力されたデータをもとに、Java から自動的にグラフを作成・更新する。
*   **別シートへの自動集計**: 日々の学習時間データを読み取り、月ごとの合計を別タブに自動で書き込む。
*   **Slack/LINE通知**: 処理が完了したことや、エラーが起きたことをチャットツールに自動で通知する。
