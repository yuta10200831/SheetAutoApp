# Sheet Auto App (スプレッドシート自動化アプリ)

Google Sheets API と Java (Spring Boot) を使用して、Google スプレッドシートの操作を自動化するアプリケーションです。
GitHub Actions を利用して、PCを閉じていても毎日自動で実行されるように構築されています。

## 🎯 現在実装されている機能

### 日次でのグループ自動開閉機能
毎日深夜0時（日本時間）になると、スプレッドシートの表示を自動的に整理します。

*   **「全体」シート（行のグループ化）**:
    *   2行目から「昨日の日付の行」までを自動でグループ化して閉じます。
    *   今日の日付の行がすぐに見える状態を維持します。
*   **「学習時間を入れていく」シート（行と列のグループ化）**:
    *   列方向: C列から「昨日の日付の列」までを自動でグループ化して閉じます。
    *   行方向: 5行目から「昨日の日付に対応する行」までを自動でグループ化して閉じます。
    *   斜めに入力していく特殊なフォーマットに合わせて、常に今日の入力箇所が左上に表示されるように整理します。

### 月別・週別学習時間の自動集計機能
*   「学習時間を入れていく」シートから日々の学習時間を読み取り、月ごとの合計時間と**今週の合計時間**を自動で計算します。
*   計算結果を「時間集計」シートに毎日自動で書き込みます。
*   スプレッドシート上で作成したグラフと連動しており、毎日自動で最新のデータに更新されます。

### LINEへの自動通知機能
*   処理が正常に完了した際や、万が一エラーが発生した際に、LINEへ自動でメッセージを通知します。
*   毎日アプリが動いていることをスマホから簡単に確認できます。

### 完全自動化（サーバーレス運用）
*   **GitHub Actions** を使用し、毎日日本時間の深夜0時に自動でプログラムが起動・実行・終了します。
*   自分のPCを起動しっぱなしにする必要はなく、サーバー代もかからない完全無料の自動化システムです。

## 🚀 実行方法

### 1. GitHub Actions での自動実行（本番環境）
*   `.github/workflows/daily-update.yml` の設定により、毎日日本時間の 0:00 に自動実行されます。
*   手動で今すぐ実行したい場合は、GitHub リポジトリの `Actions` タブ ➡️ `Daily Sheet Auto Update` ➡️ `Run workflow` から実行可能です。

### 2. ローカルでの手動実行（開発・テスト用）
開発中やテスト目的で自分のPCで動かす場合は、以下の手順を実行します。

1.  プロジェクトのディレクトリ（`sheet-app` フォルダ）に移動します。
2.  以下のコマンドを実行して、Spring Boot アプリケーションを起動します。

```bash
./mvnw spring-boot:run
```

3.  アプリケーションが起動すると、即座にスプレッドシートの更新処理が走り、処理が完了すると自動的にアプリケーションが終了します。

## 🔑 認証情報について

このアプリケーションは、Google Cloud Platform (GCP) のサービスアカウントを使用してスプレッドシートにアクセスします。

*   **ローカル開発時**: `src/main/resources/credentials.json` に鍵ファイルを配置します。
*   **GitHub Actions 実行時**: GitHub リポジトリの `Settings` ➡️ `Secrets and variables` ➡️ `Actions` にて、`GOOGLE_CREDENTIALS` という名前で鍵ファイルの中身を登録して使用します。
*   対象のスプレッドシートには、このサービスアカウントのメールアドレスに対して「編集者」権限が付与されている必要があります。

## 📅 年次更新の手順（来年以降の運用方法）

このアプリは、毎年新しいスプレッドシートを作成して運用する設計になっています（動作を軽く保ち、コードをシンプルにするため）。
毎年 **1月1日** に以下の手順を実施する。

1.  **スプレッドシートの複製**: 現在のスプレッドシートをコピーし、「2027年版 学習記録」のように名前を変更します。
2.  **シートの初期化**: コピーした新しいシートの入力データ（学習時間など）をクリアします。
3.  **シートIDの更新**: `sheet-app/src/main/java/com/example/demo/DailySheetTask.java` 内に定義されているシートIDを、新しいシートのものに書き換えます。
    ```java
    // 「全体」シートのID
    private static final int ZENTAI_SHEET_ID = 【新しいシートID】;
    // 「学習時間を入れていく」シートのID
    private static final int GAKUSHU_SHEET_ID = 【新しいシートID】;
    ```
4.  **スプレッドシートのID更新**: `application.properties` または環境変数の `SPREADSHEET_ID` を新しいスプレッドシートのIDに変更します。
5.  **権限の付与**: 新しいスプレッドシートに対して、GCPのサービスアカウント（メールアドレス）に「編集者」権限を付与します。

## 💡 今後の拡張アイデア

### 🎮 モチベーションUP
*   **連続学習日数のカウント＆通知**: 「現在10日連続学習中！」などのメッセージをLINEに通知する。
*   **目標達成アラート**: 「今週の目標まであと◯時間」や目標達成時の祝いメッセージを通知する。
*   **過去との比較**: 先週や先月と比較して、頑張りを可視化して通知する。

### 🤖 入力の自動化・外部連携
*   **LINE Bot化**: LINEから「3時間 Java」と送るだけで、スプレッドシートに自動で書き込む機能。
*   **外部ツール連携**: GitHubのコミット履歴やWakaTimeなどと連携し、作業時間を自動記録する。

### 📊 分析・AIアドバイス
*   **学習カテゴリ別の集計**: 「Java」「AWS」などタグ別に集計し、何に時間を使っているかを可視化する。
*   **AIによる振り返り**: 月末に学習データをAI（ChatGPT API等）に分析させ、パーソナライズされたアドバイスをLINEに通知する。
*   **傾向分析**: 曜日ごとの学習時間の偏りなどを分析し、習慣化をサポートする。

### 🧹 メンテナンス・UI改善
*   **古いデータの自動アーカイブ**: 1年以上前のデータを別シートに自動移動させ、メインシートを軽く保つ。
*   **条件付き書式の自動設定**: 特定の条件（例：学習時間が0時間なら赤、3時間以上なら青など）を満たすセルを自動で色付けする。
